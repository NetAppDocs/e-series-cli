= Reset storage array RLS baseline - SANtricity CLI
:icons: font
:imagesdir: ../media/

[.lead]
The `reset storageArray RLSBaseline` command resets the read link status (RLS) baseline for all devices by setting all of the RLS counts to 0.

== Supported Arrays

This command applies to any individual storage array, including the E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50, and EF80 arrays, as long as all SMcli packages are installed.

== Roles

To execute this command on an E4000, E2800, E5700, EF600, EF300, EF50, or EF80 storage array, you must have the Storage Admin role.

== Syntax
[source,cli]
----
reset storageArray RLSBaseline
----

== Parameters

None.

== Minimum firmware level

5.00
