= Set Storage Array Host I/O Protocol - SANtricity CLI
:icons: font
:imagesdir: ../media/

[.lead]
The `set storageArray hostIoProtocol` command configures the host I/O protocol at the storage array level.

== Supported Arrays

This command applies to any individual storage array, including the E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50, and EF80 arrays, as long as all SMcli packages are installed.

== Roles

To execute this command on an E4000, E2800, E5700, EF600, EF300, EF50, or EF80 storage array, you must have the Support Admin role.

== Syntax
[subs=+macros]
[source,cli]
----
set storageArray hostIoProtocol={"FC" | "ISCSI" | "ISER" | "nvmeIb" | "nvmeFc" | "nvmeRoce" | "SAS" | "SRP"}
----

== Parameter

[cols="2*",options="header"]
|===
| Parameter| Description
a|
`set storageArray hostIoProtocol`
a|
Allows you to specify which host I/O protocol to use for your storage array. Valid choices are: FC, ISCSI, ISER, nvmeIb, nvmeFc, nvmeRoce, SAS, or SRP.
|===


== Minimum firmware level

12.0
