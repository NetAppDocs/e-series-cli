= Show storage array power information - SANtricity CLI
:icons: font
:imagesdir: ../media/

[.lead]
The `show storageArray powerInfo` command returns information about the amount of power consumed by the entire storage array and each tray in the storage array.

== Supported Arrays

This command applies to any individual storage array, including the E4000, E2700, E5600, E2800, E5700, EF600, EF300, EF50, and EF80 arrays, as long as all SMcli packages are installed.

== Roles

To execute this command on an E4000, E2800, E5700, EF600, EF300, EF50, or EF80 storage array, you must have the Storage Admin or Storage Monitor role.

== Syntax
[source,cli]
----
show storageArray powerInfo
----

== Parameters

None.

== Notes

This command returns power consumption information similar to this example.

----
total power drawn: 310 watts
number of trays: 1
tray power input details:
   tray id  power supply serial number  input power
   0        0                           160 watts
   0        1                           150 watts
----

== Minimum firmware level

8.10
